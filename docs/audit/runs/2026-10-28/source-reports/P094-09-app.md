**Purpose and invariants (lines 1-400)**

The file styles the Payload admin. It sets the root and body size, font and line-height, overrides the primary button colours in an unlayered rule, and styles the Manage dashboard and its accordion. Invariants stated in the comments that the code appears to meet:

- `.lp-accordion__panel[hidden]` (line 183) has higher specificity than any `display` rule in the range, so it wins.
- `var(--lp-panel-radius)` (line 223) falls back to `4px`, so the box does not go square if the Payload variable is missing.
- The chevron is `rotate(-45deg)`, pointing right when closed, and `rotate(45deg)`, pointing down when open, driven by `aria-expanded` (lines 393, 399).
- The focus ring is inset with `calc(token * -1)` (line 285).

**Candidates**
