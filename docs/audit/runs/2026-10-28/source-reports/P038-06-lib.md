- `readActiveCapture`, `listOwnCaptures`, and `hasUnsavedWork` scope by the caller's user id. The range's comments say the id comes from the session.

- `holdsUnsavedWork` defines "unsaved work" as active, with non-null, non-`'{}'` content. `countUnsavedWorkOnVersion` and `listOwnCaptures` use it.
