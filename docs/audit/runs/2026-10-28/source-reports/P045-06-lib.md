## Purpose and invariants

- **substrand.ts:** pure logic for the browse catalogue. It groups rows into subject-grade → strand → sub-strand, orders sub-strand ids numerically, builds display labels, and applies token-AND search. Invalid ids sort last.
- **systemFacts.ts:** the read-only Manage → System panel. Its stated contract (`:28-29`) is that nothing in the module throws. A failing probe reports `unknown` instead.

## Candidates

**1. Medium (confirmed local reasoning; throw behavior unverified).** `systemFacts.ts:90`, `:149-150`, `:220`, `:222`

- **Precondition:** an environment reader throws on bad configuration. The comment at `:147-148` says `positiveIntEnv` throws, but that is not in range.
- **Expected:** `collectSystemFacts()` resolves with `unknown` rows, per the contract at `:28-29`.
- **Actual:** `gotenbergUrl()`, `artifactCacheMaxBytes()`, `artifactCacheDir()`, `isPublicLibraryEnabled()` and `errorTrackingEnabled()` are called outside any `try`. The comment at `:147-148` says the intent was to keep them inside, but the code does not. A throw would reject `Promise.all` at `:217` and fail the whole Manage page.
- **Repro:** set `ARTIFACT_CACHE_MAX_BYTES=abc` (and separately `GOTENBERG_URL` to an invalid value), then `await collectSystemFacts()`. Expect a resolved array. Confirm whether it rejects.

**2. Low (lead; expected policy not stated in range).** `substrand.ts:245-256`, `:289-291`

- Search is substring-based over `substrandId`. A query `1.4` matches `11.4` and `1.42`. A query `grade 1` matches grades 10 and 11.
- The comment at `:251` accepts substring matching for bare numbers. The comment at `:263-264` lists prefix-only matching as a future refinement. Whether these matches are wanted is not stated.

**3. Low (lead).** `substrand.ts:203-210`

- Strand groups are keyed by the numeric strand (`n${n}`), but the label comes from the first row encountered (`:210`). Two rows with the same strand number and different `unit.strand` text merge into one group. The visible label then depends on input order.
- **Repro:** rows `2.1 / "Strand 2.0: Plants"` and `2.2 / "Strand 2.0: Physiology"`, in both orders. Expect a consistent label; the actual label follows row order.

**4. Low (lead).** `systemFacts.ts:219` vs `:272-275`

- `SERVER_URL` is trimmed (`:219`), but `SMTP_HOST` is not. A whitespace-only `SMTP_HOST` reports `Ready` with status `ok`, and the detail line is suppressed (`:275`).
- `Ready` means only that the variable is non-empty. The module does not probe SMTP, and the copy does not say so.

**5. Low (lead).** `systemFacts.ts:160-190`

- Any `readdir` failure, including a cache directory that does not exist yet, reports `Cannot be checked` / `unknown`. If the directory is created lazily, a fresh install shows an unknown state where `0 used` might be the true answer. This depends on code outside the range.
