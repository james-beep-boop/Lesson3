# Lesson3 application

This directory contains the Payload CMS / Next.js application for the ARES Lesson Library. It is not
the original Payload MongoDB starter described by the old scaffold README.

- Project overview and local-server deployment: [`../README.md`](../README.md)
- Engineering commands and the pinned Node/Docker workflow: [`../AGENTS.md`](../AGENTS.md)
- Canonical product and architecture rules: [`../SPEC.md`](../SPEC.md)

Run dependency, test, lint, type, and code-generation commands through `../scripts/in-deps.sh` as
documented in `AGENTS.md`; do not install or run this production stack as a host-level npm service.
